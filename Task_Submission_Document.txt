2. PROJECT OVERVIEW & CORE FEATURES:
================================================================================
• Real-Time Messaging: Sub-millisecond communication powered by Socket.io.
• Channel & Room System: Pre-seeded topics (#general, #tech-talk, #gaming, #music, #memes) + custom channel creation.
• Room Protection & Share Links: 6-character room invite codes, shareable invite links, and password-protected private channels.
• 1-on-1 Direct Messaging (DMs): Private instant messaging between users.
• Live Online Presence Tracking: Active user counts per room and global member list.
• Dynamic Typing Indicators: Real-time animated typing status.
• Emoji Message Reactions: Interactive live-sync reactions (👍, ❤️, 😂, 🔥, 🚀, 👏).
• Persistent Cloud Storage: MongoDB Atlas storage for message history & room metadata.
• Modern Vanilla CSS Design: Responsive glassmorphism UI with Dark/Light mode and Web Audio synthesizer chimes (Strictly Zero Tailwind, Zero Next.js).
• Automated Verification: 7/7 End-to-end integration tests passing.
