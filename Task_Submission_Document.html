3. Tech Stack

  • Frontend: React.js (Vite), Material UI (MUI), Emotion, Custom CSS (No TailwindCSS)
  • Backend: Node.js, Express.js, JWT Auth, Bcrypt.js, CORS
  • Database: MongoDB (Mongoose ODM — exactly 2 collections: users and posts)
  • Deployment: Vercel (Frontend), Render (Backend), MongoDB Atlas (Database)

4. Features Implemented

  • Authentication: Secure signup & login with password hashing and JWT persistence.
  • Create Post: Post text, upload image files with preview or insert image URLs, or both.
  • Social Feed: 3-column desktop layout + TaskPlanet-inspired mobile bottom navigation bar.
  • Likes & Comments: Instant heart toggle, likers modal, and real-time comment threads.
  • Theme: Dark Mode and Light Mode with seamless switching.
